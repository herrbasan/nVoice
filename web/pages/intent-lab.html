Intent Lab

Reactive assistant turn-taking harness. Speak, then pause — the classifier decides still-speaking or turn-done, then the reply streams back. Say "wait" or "stop" to barge in.

Disconnected Silence Engine: -- listening
RTF: -- | Backlog: --
The browser's own VAD decides whether audio is sent at all, and sleeps after a few seconds of silence — the same gate the Realtime page uses. Without it every frame is streamed and the server has to judge noise it should never have seen. Turn-taking leans on this: speech wakes it, so barge-in still works. Uncheck to feed the recogniser the raw mic. Auto gain lifts the noise floor in a quiet room — the VAD then hears room noise as speech. Echo cancellation stays on either way: it is what stops the assistant hearing itself.

1200 ms — silence gap before the classifier inspects the turn. 8000 ms — fail-safe ceiling if the speaker never continues.
Playback is the barge-in window — synthesis outlives the server's reply, so the assistant is still talking after the turn is done. Say “wait”/“stop” or just keep talking to cut it. Noise does not: a bare VAD blip no longer stops playback, only speech held for about a second. The mic runs with echo cancellation while this is on, so the assistant does not hear itself.

Settings travel as WebSocket query parameters and apply on the next Start Lab.

Turn-Taking State Machine Reference
  • still-speaking: The user paused, but the classifier determined the words form an incomplete sentence/thought. Turn stays open; speech continues.
  • turn-done: The user finished a complete grammatical/semantic thought. The turn locks and passes to cleanup + assistant reply.
  • cleaning: Local LLM cleans spoken fillers (äh, ähm, halt, like, you know) and settles sentence punctuation.
  • thinking: Time-to-first-token (TTFB) while assistant LLM starts generating its answer.
  • streaming: Assistant answer tokens stream in via SSE/WebSocket.
  • interrupted (Barge-In): Spoken words starting with wait, stop, halt, hold on, hold up, never mind, belay that cancel in-flight generation immediately.
Barge-in Regex Pattern

/^\s*(wait|stop|halt|hold on|hold up|never ?mind|belay that)\b/i

Evaluated against newly arriving finals while assistant is cleaning, thinking, or streaming. If matched, cancels processing and returns to listening with zero delay.
