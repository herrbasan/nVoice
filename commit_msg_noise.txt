noise: gate the committed audio on speech mass; drop the inert client-VAD config

Issues #5 and #6 — two noise holes that stacked.

#5: min_speech_ratio decided WHEN to consider committing, but _commit() handed
the whole 1-30s buffer to the engine unchecked. A transient clearing the tail
ratio (~256ms of above-threshold audio inside the 1s tail) was transcribed in
full, and parakeet invents a plausible phrase for it — "Mr. Swiss" from a swipe
across the mic, "Breaks Audi OS" from setting the phone down. Neither is a
filler or a known invention, so the emit-time text filter passed them and the
intent gauntlet read them as a sentence.

- chunked_streaming._commit() now refuses a chunk carrying less than
  min_speech_run_sec (default 0.3s) of INTEGRATED VOICED audio — the same
  honest accumulator (_speech_run_sec: VAD fraction over new audio, each sample
  counted once) already trusted for barge-in sustain, which no plausible engine
  invention can fake.
- Skipped chunks log the measurement and emit `skipped: low-speech` telemetry,
  so the threshold stays tunable. Buffer advance factored into _advance() so the
  skip path cannot stall.
- Respects the margin by design: a deliberately short word ("stop", ~0.4s
  voiced) clears the bar, a handling transient (~0.2s) does not.
- buffer_retranscribe (faster-whisper) is left alone — it is under the explicit
  "ported VERBATIM, do not modify the heuristics" guardrail (G4), and the
  reported path is parakeet → chunked.

#6: vad.client_gate / client_threshold were declared in config and read by NO
code — a client-side gate can only live in the client, and the SDK's is an
opt-in page option (enableWakeWord(), needing the ort assets). Removed from
config.json, config.example.json, server/config.js, README and the plan docs
rather than left reading as protection that does not exist; the real gates
(min_speech_ratio, min_speech_run_sec) are now declared so they are discoverable.

tests/test_commit_gate.py — 12 checks: low-speech chunk not transcribed, skip
telemetry, no transcript emitted, buffer advanced, threshold boundary
inclusive, and that a transient integrates far below a spoken word's mass.

Docs: Agents.md (decision-vs-payload, backend-only gating), SPEC config table +
a VAD-gates section.
